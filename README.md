**EEPROM COMMUNITY MANAGEMENT SYSTEM**

EEPROM Polinema merupakan salah satu komunitas robot hobi yang ada di Politeknik Negeri Malang. Komunitas ini menjadi tempat bagi mahasiswa untuk belajar dan mengembangkan kemampuan di bidang robotika, mulai dari Robot Transporter, Robot Sumo, Robot Soccer, hingga Line Follower.

Selain belajar teknis robotika, EEPROM Polinema juga memiliki struktur organisasi di dalamnya. Setiap anggota memiliki peran dan tanggung jawab masing-masing dalam menjalankan kegiatan komunitas. Oleh karena itu, dibuat sebuah EEPROM Community Management System yang bertujuan untuk membantu pengelolaan komunitas agar lebih tertata dan mudah dikelola.

Sistem ini terdiri dari tiga bagian utama, yaitu halaman utama yang dapat diakses oleh publik, member area yang hanya bisa diakses oleh anggota EEPROM, serta admin panel yang digunakan untuk mengelola website. Dalam pembuatannya, sistem ini menerapkan konsep MVC (Model-View-Controller) supaya struktur folder dan file lebih rapi, sehingga ke depannya memudahkan proses pengembangan maupun maintenance oleh tim.

**Teknologi yang Digunakan**

1. PHP dengan arsitektur Custom MVC sebagai backend
2. HTML5, CSS3, JavaScript, dan Bootstrap 5 sebagai frontend
3. PostgreSQL sebagai database
4. Composer untuk mengelola dependency
5. Bootstrap Icons dan Font Awesome sebagai ikon pendukung

**Fitur Utama**

**1. Admin Panel**
Digunakan oleh admin untuk mengelola data anggota, konten dan pengumuman, dokumentasi kegiatan, serta pengaturan lainnya.
**2. Member Area**
Halaman khusus anggota untuk mengelola profil, melihat riwayat kehadiran setiap pertemuan, dan mendapatkan informasi terbaru seputar EEPROM.
**3. Public Facing Pages**
Halaman utama yang bisa diakses oleh publik dan berisi informasi tentang EEPROM, termasuk formulir rekrutmen bagi mahasiswa yang tertarik untuk bergabung.
**4. Voting System**
Fitur pemilihan ketua umum EEPROM di setiap periode kepengurusan melalui sistem voting, baik internal maupun eksternal, yang dilakukan secara transparan.
